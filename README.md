# Zeeshan Ahmad — Portfolio

Static site (HTML, CSS, JS). No build step.

- `index.html` — home
- `sindh-ombudsman.html` — Sindh Ombudsman case study (served at /sindh-ombudsman)
- `sindh-ombudsman-wireframes.html` — all wireframes (served at /sindh-ombudsman-wireframes)
- `assets/` — styles, script, images, CV

## Deploy on Vercel
1. Push this folder to a GitHub repository.
2. In Vercel: Add New → Project → import the repository.
3. Framework preset: **Other**. Leave build command and output directory empty.
4. Deploy.

To update: change files, commit and push. Vercel redeploys automatically.
